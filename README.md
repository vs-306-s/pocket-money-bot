# 💰 Карманные деньги по оценкам — Telegram-бот

Бот считает карманные деньги по школьным оценкам. Ты присылаешь фотографии дневника,
классного журнала или табеля — нейросеть читает оценки, бот считает деньги по твоим
ставкам и коэффициентам, а в конце собирает всё в аккуратную таблицу Excel.

```
сумма за оценку = ставка за оценку × коэффициент предмета
```

Пример: ставка за «5» = 300 ₽, коэффициент по математике ×2 → за пятёрку придёт **600 ₽**.
Двойка со ставкой −300 ₽ и коэффициентом ×2 → **−600 ₽**.

## Что умеет

| Возможность | Как |
|---|---|
| 📸 Читать оценки с фото | пришли фото (можно сразу несколько) — нейросеть распознает дату, предмет и оценку, потом спросит подтверждение |
| ➕ Добавлять вручную | `/add 5 математика 15.09` или пошагово через `/add` |
| 💰 Считать деньги | стартовая сумма + ставки за «5», «4», «3», «2» − списания за плохие оценки |
| ✖️ Коэффициенты по предметам | математика ×2, физика ×1.5, любой предмет — свой множитель |
| 📊 Отчёт в Excel | три листа: «Оценки», «Сводка» с диаграммой, «Настройки» |
| 🤖 Свой ключ нейросети | ключ подключает сам пользователь (гайд — `/guide` и [ГАЙД-API-КЛЮЧИ.md](ГАЙД-API-КЛЮЧИ.md)) |
| 📋 История | `/list` — последние записи с возможностью удалить, `/undo` — убрать последнюю |

## Быстрый старт

```powershell
# 1) зависимости (python 3.10+)
pip install -r requirements.txt

# 2) настройки
copy config.example.json config.json
#    впиши bot_token от @BotFather

# 3) запуск
python main.py
```

На Windows удобнее `start_bot.bat` (автоперезапуск) или `run_hidden.vbs` (без окна консоли).

Дальше в Telegram: `/start` → ⚙️ Настройки → задать стартовую сумму, ставки и коэффициенты →
🤖 Нейросеть → подключить ключ → прислать фото дневника.

## Как бот считает деньги

1. **Стартовая сумма** — «сколько денег было на начало» (⚙️ Настройки → 💵 Стартовая сумма).
2. **Ставки за оценки** — сколько приходит/списывается за каждую оценку:
   `{"5": 300, "4": 150, "3": -100, "2": -300}` — минус значит списание.
3. **Коэффициенты по предметам** — множители вида `{"математика": 2, "физика": 1.5}`.
   Название предмета сравнивается без учёта регистра и «ё»; коэффициент по «математика»
   сработает и для «Математика (алгебра)».
4. Остаток = стартовая сумма + все начисления − все списания. В отчёте видно и то,
   сколько было на начало периода, и сколько стало в конце.

Оценки, для которых ставка не задана, записываются с нулём — бот предупредит об этом.

## Отчёт в Excel

Файл собирается на каждом запросе и сразу удаляется после отправки.

**Лист «Оценки»** — таблица ровно в таком порядке, как удобно смотреть глазами:

| Дата | Предмет | Оценка | Коэффициент | Ставка | Сумма | Комментарий |
|---|---|---|---|---|---|---|
| 15.09.2026 | Математика | 5 | ×2 | 300 ₽ | 600 ₽ | контрольная |
| 16.09.2026 | Физика | 4 | ×1.5 | 150 ₽ | 225 ₽ | |
| 17.09.2026 | История | 3 | ×1 | −100 ₽ | −100 ₽ | |

Есть закреплённая шапка, автофильтр, чередование строк, зелёные плюсы и красные минусы,
строка «ИТОГО» живой формулой `=SUM(...)`.

**Лист «Сводка»** — стартовая сумма, начислено, списано, изменение, остаток на конец,
средний балл, разбивка по предметам (оценок, средний балл, суммы) и по оценкам,
плюс столбчатая диаграмма «Итого по предметам».

**Лист «Настройки»** — с какими ставками и коэффициентами считался отчёт
(ключ нейросети в файл не попадает).

## Ключ нейросети

Бот не платит за распознавание: ключ подключает сам пользователь, запросы идут
напрямую к провайдеру (`/key` → выбрать провайдера → прислать ключ). Сообщение с ключом
бот удаляет, ключ хранится только в локальной базе.

Провайдеры: **OpenRouter**, **Google Gemini**, **OpenAI**, **Groq**, **Mistral**,
**DeepSeek** (без чтения фото) и любой свой OpenAI-совместимый сервер.
Есть бесплатные варианты — подробный гайд: команда `/guide` в боте и
[ГАЙД-API-КЛЮЧИ.md](ГАЙД-API-КЛЮЧИ.md).

## Команды бота

| Команда | Что делает |
|---|---|
| `/start` | приветствие и меню |
| `/photos` | как правильно присылать фото |
| `/add [оценка предмет дата]` | добавить оценку вручную |
| `/list` | последние оценки (с удалением) |
| `/undo` | убрать последнюю запись |
| `/balance` | баланс карманных |
| `/report` | Excel за месяц / прошлый месяц / 30 дней / год / всё время / свой период |
| `/settings` | стартовая сумма, ставки, коэффициенты, валюта, часовой пояс |
| `/key` | подключить ключ нейросети |
| `/guide` | где взять ключ |
| `/cancel` | отменить текущий ввод |
| `/admin` | служебная информация (только для владельца) |

## Приватность

* Фото скачиваются в память, отправляются в нейросеть пользователя и нигде не сохраняются.
* Ключ нейросети хранится только в `data/bot.db` и никогда не выводится в чат и в Excel.
* `config.json`, `data/` и `gh_token.txt` исключены из git (`.gitignore`).
